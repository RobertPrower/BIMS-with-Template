# 🏘️ Barangay Information Management System (BIMS)

A browser-based web application developed as our Capstone Project for Barangay 177, Caloocan City. The system aims to **streamline resident records, document processing, and blotter reports** within the barangay through a centralized, digital platform.

This project was built using front-end and back-end web technologies, and evaluated based on **user acceptance**, **software quality standards (ISO 25010)**, and the **Technology Acceptance Model (TAM)**.

---

## 🎯 Project Objectives

- Replace the manual document processing system used in the barangay
- Enable secure, centralized, and fast access to resident records
- Generate tamper-resistant certificates using QR codes
- Improve usability, performance, and reliability of barangay operations
- Provide separate modules for different departments: Secretariat, Clearance, and Lupon

---

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, Bootstrap, JavaScript, AJAX, jQuery
- **Backend**: PHP
- **Database**: MySQL
- **Server**: Apache (XAMPP)
- **Version Control**: Git, GitHub
- **Additional**: QR Code Generator for document security

---

## 🧩 System Modules & Features

- **Admin Dashboard**: User account and activity management, database backup
- **Clearance Department**: Certificate of Residency, Bail Bond, Business Permits, etc.
- **Secretariat Department**: Certificates of Indigency, PWD, Solo Parent
- **Lupon Department**: Blotter reporting and conflict management
- **QR Code Integration**: Each issued document includes a QR code for authenticity verification
- **Audit Trail**: Tracks system usage and document issuance
- **User Access Control**: Roles and permissions for each department

---


## 📊 Evaluation Highlights

### ✅ **User Acceptance Test**
- **Overall score**: 4.55 – *Highly Acceptable*
- Users found the system useful, easy to use, and aligned with their work needs

### ✅ **System Quality (ISO 25010)**
- **Overall score**: 4.38 – *Acceptable*
- Rated highly in usability, functional suitability, and maintainability

## 🔧 Installation (For Local Testing)

1. Clone this repository: 

git clone https://github.com/RobertPrower/BIMS-with-Template

2. Open `XAMPP` or any local server environment
3. Place the project folder in `htdocs/`
4. Import the SQL database from `/database/bims.sql` using phpMyAdmin
5. Run the project in your browser:  
`http://localhost/bims-with-template/index.php`
